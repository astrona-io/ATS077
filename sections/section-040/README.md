# Platform Architecture and Capabilities

This section covers Platform Architecture and Capabilities. Its module, Capability Layers, Control Planes And Supported Interfaces, has three parts: Capability Layers And Supported Interfaces, A Custom Resource As A Platform API, Guardrails, Failure Domains And Ownership. Each part explains the mechanism and walks through commands you run yourself.

Read the landing page, the three parts and the summary in order. The module has a playground for free exploration and a graded module lab, Custom Resource As A Platform API Lab. The section ends with a graded capstone lab, Platform Architecture Capstone, and a quiz. The labs were built without being run and are marked untested.

## Learning Outcomes

- Describe platform capability, control and implementation layers.
- Distinguish developer interfaces from the systems performing work.
- Reason about composability, failure domains and ownership.
