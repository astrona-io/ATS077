# Get Your Machine Ready

A Markdown reader or the Astrona reading interface is sufficient. Mermaid diagrams describe relationships also explained in the surrounding text.

The hands-on parts run in a playground: a disposable kind (Kubernetes in Docker) cluster that the `astrona` command starts for you. You need Docker (or a compatible container runtime), the `astrona` command-line tool and `kubectl` on your machine. Each module has a playground for free exploration and a graded lab; each section has a capstone lab.
