# Application Environments and Infrastructure Concepts

This section covers Application Environments and Infrastructure Concepts. Its module, Environment Boundaries, Dependencies And Resource Isolation, has three parts: Environments And The Boundaries That Separate Them, Quotas, Limits And Capacity Isolation, Identity, Data And Environment Lifecycle. Each part explains the mechanism and walks through commands you run yourself.

Read the landing page, the three parts and the summary in order. The module has a playground for free exploration and a graded module lab, Quota, Defaults And Parity Lab. The section ends with a graded capstone lab, Environment Boundaries Capstone, and a quiz. The labs were built without being run and are marked untested.

## Learning Outcomes

- Distinguish development, test and production environments by purpose.
- Explain identity, data and capacity separation.
- Reason about configuration parity without assuming identical conditions.
