# Continuous Delivery and GitOps

This section covers continuous Delivery and GitOps. It develops gitOps And Deployment Configuration through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain declarative, versioned desired state.
- Describe pull-based reconciliation and drift correction.
- Compare Helm templating with Kustomize overlays.
- Identify what a GitOps controller cannot infer from repository state.
