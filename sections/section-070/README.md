# Continuous Delivery and GitOps

This section covers Continuous Delivery and GitOps. Its module, GitOps And Deployment Configuration, has three parts: GitOps Reconciliation And Drift, Helm, Kustomize And Configuration Rendering, Promotion Through Git And Revision Evidence. Each part explains the mechanism and walks through commands you run yourself.

Read the landing page, the three parts and the summary in order. The module has a playground for free exploration and a graded module lab, GitOps Delivery Lab. The section ends with a graded capstone lab, GitOps And Deployment Capstone, and a quiz. The labs were built without being run and are marked untested.

## Learning Outcomes

- Explain declarative, versioned desired state.
- Describe pull-based reconciliation, drift and self-heal with an Argo CD Application.
- Compare Helm templating with Kustomize overlays.
- Identify what a GitOps controller cannot infer from repository state.
- Promote a change through a Git commit and tie it to the revision the controller synced.
