# DevOps Practices in Platform Engineering

This section covers DevOps Practices in Platform Engineering. Its module, Shared Ownership, Feedback And Platform Enablement, has three parts: Shared Ownership And Platform Enablement, Feedback Signals: Probes, Rollouts And Rollback, DevSecOps Guardrails In The Platform. Each part explains the mechanism and walks through commands you run yourself.

Read the landing page, the three parts and the summary in order. The module has a playground for free exploration and a graded module lab, Ownership, Probes And A Restricted Namespace Lab. The section ends with a graded capstone lab, DevOps Practices Capstone, and a quiz. The labs were built without being run and are marked untested.

## Learning Outcomes

- Explain DevOps and DevSecOps as collaborative practices.
- Distinguish platform enablement from transferring every responsibility.
- Reason about feedback, security and supported service boundaries.
